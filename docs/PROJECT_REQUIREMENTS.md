# 직친 프로젝트 기능 기준

이 문서는 사용자가 설명한 현재 프로젝트 방향을 기록합니다. 구현 완료 여부와는 별개이며, 이후 사용자가 기능을 변경하거나 추가하면 그에 맞춰 갱신합니다.

## 서비스 대상

- 성인만 사용할 수 있는 스포츠 직관 동행 앱입니다.

## 가입 및 프로필 완성

1. 소셜 로그인으로 회원가입합니다.
2. 이름, 나이, 성별은 PASS 인증으로 진행하거나, 성인임을 인증할 수 있는 방식을 사용합니다. 구체적인 인증 방식은 확정되지 않았습니다.
3. 닉네임을 설정하고 중복 여부를 확인하며, 프로필 사진과 한 줄 소개를 작성합니다.
4. KBO와 K리그 응원팀을 각각 설정할 수 있습니다. 응원팀이 없으면 각 선택을 건너뛸 수 있습니다.

## 직관 방과 채팅

- 사용자는 방을 생성하거나 방 목록을 보고 원하는 방에 참여할 수 있습니다.
- 방 생성 시 방 제목, 날짜, 어느 팀 대 어느 팀의 경기인지와 경기장, 방장을 포함한 최대 인원 등을 정합니다.
- 방을 생성한 사용자는 방장입니다.
- 방은 채팅방 형식입니다.
- 한 사용자가 여러 방에 동시에 참여할 수 있고, 여러 방을 생성할 수도 있습니다.
- 참여자는 방을 나갈 수 있습니다. 방장이 나가면 남아 있는 참여자 중 가장 먼저 입장한 사람에게 방장을 자동 위임합니다. 이미 나간 사람은 제외합니다.
- 방장 혼자 있는 방에서 방장이 나가면 방은 자동으로 삭제됩니다.

## 마이페이지

- 닉네임, 프로필 사진, 한 줄 소개, 응원팀 등을 확인하고 수정할 수 있습니다.
